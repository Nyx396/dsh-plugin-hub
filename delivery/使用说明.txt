DSH 扩展口袋与插件配置
插件名称：dsh-plugin-hub

一、它提供什么
1. 聊天输入框旁增加“小方框中的加号”入口，集中显示由扩展主动注册的特殊功能。
2. 设置侧栏增加“插件配置”，带搜索，方便定位已收纳的插件设置。
3. 当前收纳“启动动画”和“聊天背景”；它们的原有设置页面和配置数据继续使用。
4. OAuth、Token 用量保留原侧栏入口。今后的插件可通过扩展注册接口选择加入。
5. 本包提供收纳与入口基础设施，不包含尚在设计阶段的视频/GIF抽帧插件。
6. 搜索匹配插件设置页的名称和注册关键字，不是对每个设置字段进行全文搜索。

二、适用范围
Windows 64 位的 DeepSeek Harness Desktop。DSH 版本范围以 plugin/package.json 的 engines.dsh 为准；
只对实际验证过的版本声明兼容。不要把整个 .dsh 或别的机器上的链接路径覆盖到目标机器。
插件已预构建，不要求另外安装 Node、Python 或 npm 包；安装使用目标 DSH 自带的命令行和运行时。

三、安装
1. 把整个 ZIP 解压到任意普通目录，不能直接在压缩包预览窗口里运行。
2. 完全退出 DSH，包括托盘图标。脚本不会擅自结束进程。
3. 可先双击“检查环境.cmd”；它只报告路径、插件包和运行状态，不修改设置。
4. 双击“安装.cmd”，等待显示 Install complete，再打开 DSH。
5. 确认输入框旁有方框加号，设置侧栏出现“插件配置”；启动动画与聊天背景位于其中。

安装器把插件复制到：
  <DSH_HOME>\custom-plugins\dsh-plugin-hub\<profile>
默认 DSH_HOME 是当前用户的 .dsh，默认 profile 是 desktop。
之后可以移动或删除解压目录；已经安装的插件不依赖解压目录，更不依赖 F 盘。
包管理操作明确使用离线模式。离线条件不满足时会报告失败并回滚，不会静默改为联网下载。

四、自定义 DSH 路径、DSH_HOME 或 profile
如果未能自动识别，可以在 PowerShell 中进入解压目录，执行：
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\portable.ps1 -Mode Check -DshPath "D:\Apps\DeepSeek Harness" -DshHome "D:\DSH Data" -Profile desktop
确认路径正确后，把 Check 改成 Install。DshPath 也可以直接指向 DSH 自带的 dsh.cmd。
含中文和空格的路径需要保留双引号。已有 profile 必须先由 DSH 初始化；安装器不会创建或覆盖整套个人配置。

五、卸载与故障恢复
完全退出 DSH，双击“卸载.cmd”。它只移除此 profile 中的 dsh-plugin-hub，保留其他插件、模型与会话设置。
只要原插件仍在，原来的启动动画、聊天背景入口会恢复。
安装或卸载失败时，本次事务会尽量恢复操作前的 profile 元数据和本插件文件。
备份保存在 <DSH_HOME>\backups\dsh-plugin-hub\时间戳-编号；出现回滚失败时，保存报错及备份路径。
不要把旧备份整套覆盖回后来已经改过的 profile；那样可能覆盖之后添加的其他插件设置。

六、常见情况
扩展动作：默认提供“插件配置”快捷入口；其他特殊功能在对应扩展注册后显示。
看不到启动动画或聊天背景：先确认原 dsh-boot-suite 插件已安装并启用；本插件不会代装它。
原插件被卸载或临时不可用：插件配置不伪造设置页，也不改动原设置数据。
提示 DSH 正在运行：完全退出后再重试。
提示路径是重解析点：安装器为避免操作链接指向的其他目录而停止；请选择普通目录。
脚本未自动提权；自定义受保护的安装位置可能需要由你选择有写权限的 DSH_HOME。

七、交付文件
使用说明.txt、安装.cmd、卸载.cmd、检查环境.cmd、tools/portable.ps1、预构建 plugin/、SHA256SUMS.txt。
ZIP 旁的 .sha256.txt 是整个压缩包的校验值，包内 SHA256SUMS.txt 用于校验各交付文件。
